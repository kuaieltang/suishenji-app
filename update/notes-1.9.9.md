- 「问」：直接问自己的记录。统计类（「我这个月花了多少钱」）由本机算好数字再让模型说人话，回忆类（「上次给妈打电话是什么时候」）直接读原始记录。需要配一个你自己的大模型 API Key（设置 → 大模型），不配也不会影响其他功能。
- 小助理：问它就是跟自己聊天，名字和头像都能改。
- 「人物」：自动从记录里抽出你提到的人，算最近 3 个月的提及次数，支持别名、星标、备注、关系。同一个人在不同句子里可能指不同的人，这种会单独问你一句，不瞎猜。
- 「个人设置」（新增）：昵称、头像、家庭成员。家人从「人物」移到这里，不再重复显示。
- 首页改成四种状态：空闲 / 录入中 / 待提交 / 提交成功。说话的时候还没确认的那几个字是橙色的，识别完成后变回墨色，右上角有计时。
- 保存后顶部会出现「已提交第 N 条」，2 秒内点「撤销」可以把这条删掉、文字放回输入框接着改。
- 主页面可以左右滑动：左滑是「问」，右滑是「查」。底部操作行重排成「问 | 保存 | 今天 N 条」，中间是唯一的橙色按钮。
- 金额和分类已经在悄悄攒（日期、金额、是否概数、分类、关联的人），账单页还没做。
